# LUMI (루미)

> **안부를 묻는 데서 끝나지 않고, 후속 조치까지 연결하는 복지업무 지원 파트너**

LUMI는 지자체·복지기관의 **독거노인 안부 확인 업무**를 효율적으로 관리할 수 있도록 기획한 복지업무 지원 서비스입니다. 현재 저장소에는 담당자가 안부 확인 현황과 우선 확인할 업무를 한눈에 살펴볼 수 있는 **대시보드 UI 프로토타입**이 구현되어 있습니다.

> [!IMPORTANT]
> 현재 `lumi.html`은 **프런트엔드 시연용 프로토타입**입니다. 화면에 표시되는 대상자 정보와 건수는 예시 데이터이며, 실제 전화 연동·AI 분석·서버 저장·후속 조치 자동화는 구현되어 있지 않습니다.

## 1. 프로젝트 배경

독거노인 안부 확인 업무는 단순한 전화 응답 여부만으로 끝나지 않습니다. 미응답 원인은 외출, 입원, 기기 문제 등으로 다양하며, 담당자는 재연락과 후속 조치 여부를 함께 관리해야 합니다. 기록이 전화 내역이나 수기 메모에 분산되면 반복 업무가 늘고 확인이 필요한 사례를 놓칠 위험도 있습니다.

LUMI는 **안부 확인 → 결과 파악 → 추가 확인 → 후속 조치**의 업무 흐름을 하나의 화면에서 지원하는 것을 목표로 합니다.

## 2. 현재 구현된 화면

### 대시보드

- **오늘의 안부 확인 현황**: 금일 확인 예정, 확인 결과 입력, 추가 확인 필요, 조치 진행 중 건수를 카드로 표시
- **우선 확인할 업무**: 대상자, 안부 결과, 최근 확인 시간, 담당자, 후속 상태를 표로 표시
- **상태별 배지**: `미응답`, `도움 요청`, `응답 완료`, `연결 오류`를 구분하여 표시
- **사이드바 메뉴**: 대시보드, 대상자·일정, 안부 확인 기록, 후속 조치 관리, 요약 보고 항목 제공
- **프로필 메뉴 및 환경 설정**: 설정 창을 열고 테마 및 표시 해상도를 변경

### 화면 설정

| 항목 | 지원 옵션 |
| --- | --- |
| 테마 | Warm Orange, Trust Blue, Healing Green, Dark Mode, Clean Mono |
| 표시 크기 | 1920 × 1080, 1280 × 720 |
| 기본 테마 | Warm Orange |
| 기본 표시 크기 | 1920 × 1080 |

**참고:** 사이드바를 클릭하면 선택된 메뉴명이 변경되지만, 각 메뉴에 대응하는 별도의 상세 페이지는 아직 없습니다. 검색창·알림·`전체 보기`·`처리하기` 등도 현재는 실제 데이터 처리 기능과 연결되지 않은 UI 요소입니다. 설정 값은 페이지를 새로고침하면 초기화됩니다.

## 3. 기술 스택

| 구분 | 기술 | 용도 |
| --- | --- | --- |
| 구조 | HTML5 | 기본 화면 구성 |
| 스타일 | Tailwind CSS (CDN) | 레이아웃, 테마 및 UI 스타일 |
| 동작 | Vanilla JavaScript | 화면 렌더링 및 상태 변경 |
| 아이콘 | Lucide Icons (CDN) | 메뉴·버튼·상태 아이콘 |

별도 프레임워크, 패키지 매니저 또는 빌드 과정 없이 **단일 HTML 파일**로 실행됩니다.

## 4. 실행 방법

### 준비 사항

- 최신 웹 브라우저 (Chrome, Edge 등)
- **인터넷 연결**: Tailwind CSS와 Lucide Icons를 CDN에서 불러오기 위해 필요

### 로컬 실행

1. 저장소를 내려받거나 `lumi.html` 파일을 준비합니다.
2. `lumi.html` 파일을 웹 브라우저로 엽니다.
3. 대시보드의 요약 카드 및 업무 목록을 확인합니다.
4. 오른쪽 상단 프로필의 **설정** 메뉴에서 테마와 표시 크기를 변경할 수 있습니다.

별도의 설치 명령어나 개발 서버는 필요하지 않습니다.

## 5. 프로젝트 구조

```text
.
├── lumi.html      # 대시보드 UI 및 JavaScript 로직
└── README.md      # 프로젝트 소개 및 실행 안내
```

`lumi.html` 내부에는 예시 데이터(`summaryCards`, `priorityTasks`), 메뉴 정의(`menuItems`), 테마 설정(`themes`), 화면 상태(`state`), UI 렌더링 함수(`render`)가 포함되어 있습니다.

## 6. 향후 개발 방향

다음 항목은 **서비스 기획 단계의 목표이며 현재 HTML 파일에 구현된 기능은 아닙니다.**

- **대상자·일정 관리**: 대상자 등록, 담당자 배정, 안부 확인 일정 관리
- **통화 기록 연동**: 안부 확인 통화 내역의 자동 수집 및 저장
- **AI 기반 요약**: 통화 내용 요약과 확인이 필요한 주요 사항 정리
- **미응답 관리**: 미응답 사유 구분 지원 및 재연락 일정 관리
- **후속 조치 추적**: 담당 기관·가족 등과의 연계 업무 및 처리 상태 기록
- **요약 보고**: 기간별 안부 확인 현황과 후속 조치 통계
- **운영 환경 구축**: 인증·권한 관리, 데이터베이스 연동, 개인정보 보호 및 접근 기록 관리

AI 분석 결과는 담당자의 판단을 돕는 참고 정보로 활용하며, 위험 여부 및 현장 조치는 담당자의 확인 절차를 전제로 설계할 예정입니다.
